# Tamlinux agent skills

The product maintains `tamlinux` and `diagnose-crash` under
`desktop/skills/`. They cover desktop inspection, configuration ownership
and requested crash diagnosis.

Use the installed discovery entry when it resolves to current instructions.
Bundle deliveries carry the skills under
`/usr/lib/tamlinux/current/share/tamlinux/skills/`. If an agent's discovery
link is broken or the installed instructions predate the source-install
transition, read the corresponding `SKILL.md` in a Tamlinux checkout.
Confirm the live host's selected runtime separately.

The former Home Manager registration and rollback procedure remains in Git.
Automatic discovery for the Make delivery belongs to the source-install
rollout. Keep personal entries in their existing discovery directories.
