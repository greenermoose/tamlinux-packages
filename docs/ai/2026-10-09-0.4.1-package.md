## Change and decisions

Fred accepted Tamlinux 0.4.1 as the shell at `a0d7737` with plugins installed
from private copies. Packaged deployment needs every installed part to come
from one product revision, so the 0.4.1 package is rebuilt from public
sources and goes through Test before release.

- **Product line `release/0.4.1`** starts at `a0d7737` and adds the eight
  plugins exactly as installed at acceptance (each payload digest equals the
  acceptance record), the product commands `tam-work`, `tam-deploy` and
  `tam-plugin`, and `VERSION` 0.4.1. Shell and protocol shadow files are
  unchanged.
- **Assembly** pins that line with the component versions that ran (`tam`
  0.7.0 code, `libtam` 0.2.0, `tamlinux-tools`). A tools module installs `tam`,
  its guide and `tam-file-select`; the guide is linked where `tam` looks
  before system data directories, so another installed guide cannot shadow it.
