endpoints, and replaces inherited marketplace lookup with its shipped plugin
catalog. This delivery change supplies runtime tools for those helpers: standard
systemd programs, jq, Perl, coreutils, grep/find/diff/awk and Python/Git where
used. Wrappers resolve helper-to-helper calls from the same command output,
then retain the caller's PATH for host prerequisites and selected applications.
Node.js and Perl are also declared for command integration checks.

adapters remain explicit host/assembly requirements; these recipes do not claim
the complete desktop closure is ready. No source pin or candidate letter was
changed. The current assembly and installed workstation are unchanged.
