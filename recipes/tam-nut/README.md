# Arch tam nut

Build this development bootstrap with `makepkg --check`. Its source
commits are pinned in `PKGBUILD`. The package contains the static bundle
tool, welcome and hardware inspection command, console aliases, Arch
profile, polkit actions, boot unit and Pacman hooks.

The `start` alias requires completed system/settings agreement.
The fixed polkit helper accepts no arguments and applies an authorized
prepared transaction. Native removal checks preserve required providers.
The post-transaction check reports retained runtime incompatibilities.

Installing this package conflicts with the existing native adapter.
Replacement, dormant-slot conversion, console activation and recorded
delivery integration require the migration procedure and its approvals.
Building this package installs nothing on the host.
